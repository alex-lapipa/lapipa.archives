# Documentary production workflow

## Editorial objective

Documentary work may interpret evidence, but it must preserve the path back to that evidence. The production record should allow a later researcher to understand what was selected, omitted, transformed, licensed, translated, or contested.

## Research and development

1. Create a research question and evidence brief.
2. Search the provenance-aware corpus and inspect cited sources rather than relying on generated summaries.
3. Create candidate story claims with status: verified, attributed, disputed, inferred, or unresolved.
4. Build a chronology with source-level support and explicit date uncertainty.
5. Identify missing voices, archival silences, conflicts, and foreseeable harms.

## Interview production

Create a session item before recording. Link the participant, interviewer, location, date, consent, release status, recording devices, cards or files, and production notes. After capture, ingest camera and sound originals before syncing or editing. Slate and preserve each take. Transcribe from a named representation and verify quotes against picture and sound.

## Edit and fact-check

Every factual assertion in a script or cut receives a claim ID or source citation. Quotes retain item, representation, and time range. Visuals retain item and rights IDs. Music and artwork retain license evidence. Fact-checking tests the actual wording and edit context, not only the general topic. Material changes after fact-check trigger review again.

## Version control

Preserve scripts, paper edits, transcripts, cue sheets, music logs, rights logs, subtitle files, credits, review notes, picture-lock exports, and final masters as versioned records. Editing project files require dependency and plugin documentation sufficient to assess future renderability.

## Release gate

A documentary release requires editorial approval, citation audit, rights clearance, participant/consent review where applicable, privacy and harm review, accessibility assets, technical QC, fixity, preservation ingest, credits, and a public access decision. The release package includes a manifest and checksums.

## Corrections

Corrections are versioned and explained. A new cut does not erase the released cut. Material factual corrections update the knowledge claim, documentary record, public notice, and any affected access derivative while preserving prior evidence and decision history.
